
# Student Marks Calculator

## About
A beginner-friendly Python project that calculates a student's total marks, average marks, and pass or fail result.

## Features
- Accepts the student's name
- Takes marks for three subjects
- Calculates total marks
- Calculates average marks to two decimal places
- Displays Pass or Fail

## Requirements
- Python 3

## How to Run
1. Open the terminal.
2. Navigate to the project folder.
3. Run the command:

   python3 main.py

## Concepts Used
- Variables
- User input
- Data types
- Arithmetic operations
- Conditional statements
